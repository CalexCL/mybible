SOURCE INTEGRITY

资料来源政策

本项目只允许经核实的主流新教／福音派圣经研读来源进入神学与经文参考层。

✓
严格排除： Jehovah's Witnesses、Mormon/LDS、Roman Catholic doctrinal/commentary sources、cult-affiliated material，以及无法核实宗派背景的神学资料。

资料分层规则

SCRIPTURE

经文本身。绝不让注释改写或混入经文。

ORIGINAL LANGUAGE

希伯来文、亚兰文、希腊文、词形与词义资料。

CROSS REFERENCE

经文解释经文的串珠资料。

HISTORICAL

地理、考古、年代背景；不作为神学权威。

COMMENTARY

解释层必须具名、标来源，不冒充经文。

USER

个人笔记、书签、祷告与标记。
